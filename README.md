# Text_Classifier       
    
НС для классификации текста.       
        
**Задача:**     
Обучить модель определять автора исходного текста.    
        
**Что сделано:**    
Проведена предобработка и балансировка обучающих данных. Инициализирована и обучена модель, определяющая автора исходного текста.      
       
**Использованные технологии:**       
Keras, Scikit-learn, TensorFlow       
      
**Результаты**     
Модель определяет автора текста с точностью 97%.      
        
**Как запустить проект**       
Создайте блокнот в Google Colab     
Скопируйте код из main.ipynb      
Запустите выполнение кода
